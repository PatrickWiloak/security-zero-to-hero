## Who this is for

You want to understand security, but:

- You're not preparing for an exam (or not yet)
- You want context and intuition, not 200-question fact dumps
- You'd rather learn **why** a control exists before memorising vendor settings
- You're a developer, IT or ops engineer, founder, PM, or someone moving into security

If you **do** want certifications, head to the **[Study Hub](../STUDY-HUB.md)**, where every security certification on this site is indexed.

## Why this exists

Most security content is either:

1. **Cert-shaped** - exam objectives, fact sheets, practice questions (great if you have an exam date, useless if you just want to understand)
2. **Vendor marketing** - "stop every threat with our platform!" (no actual technical content)
3. **Deeply specialised** - exploit write-ups and research papers that skip the fundamentals you'd need to follow them

This hub is the missing middle: technical, accurate, plain English, no exam scaffolding.
