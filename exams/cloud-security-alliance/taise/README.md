# CSA TAISE - Trusted AI Safety Expert Certificate

A knowledge certificate from the Cloud Security Alliance, built with Northeastern University, covering AI from fundamentals through generative AI architecture, ethics, threats, governance, security, cloud, data privacy and continuous improvement. The exam is open-book, so the skill is knowing where ideas live and applying them, not memorizing. For the AI-side material see [AI safety at ai.noblerworks.com](https://ai.noblerworks.com/safety/).

## Exam Details

- **Duration:** 120 minutes
- **Questions:** 60 multiple-choice, 6 per module across 10 modules
- **Format:** online, open-book, unproctored
- **Passing Score:** 80%
- **Cost:** US$795 training and exam bundle with two attempts (CSA, checked 2026-11-07)
- **Prerequisites:** none required

Full detail, with sources, in the [fact sheet](./fact-sheet.md).

## How the exam thinks

With a published pass mark of 80% (48 of 60) and an open-book format, the exam rewards breadth and care. Every module counts equally, so a weak module costs you the same as a weak strength gains. Read each question for the specific module idea it tests, and use the open-book time to confirm, not to learn.

## Study sequence

Follow CSA's module order. Modules build on each other: fundamentals, then generative AI, then risk and threat, then security and data.
