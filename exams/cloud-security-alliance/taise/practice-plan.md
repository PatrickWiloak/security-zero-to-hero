# CSA TAISE Study Plan

Three weeks at 5-7 hours a week. The exam is open-book, but 60 questions in 120 minutes leaves about two minutes each, so you must know where to look. All ten modules count equally (6 questions each).

## Week 1: Fundamentals and generative AI (modules 1-4)

- [ ] Read notes 01 and 02
- [ ] Read the NIST AI RMF Section 3 on trustworthy characteristics and the OECD AI Principles

## Week 2: Lifecycle, threats, governance, security and cloud (modules 5-8)

- [ ] Read notes 03 and 04
- [ ] Read the NIST AI 100-2 attack-goal summary and the OWASP LLM Top 10 list
- [ ] Skim the CSA AI Controls Matrix page

## Week 3: Data, learning and practice (modules 9-10)

- [ ] Read note 05
- [ ] Work through the [practice questions](../../../resources/practice-questions/csa-taise.md); read every explanation
- [ ] Work through the [scenarios](./scenarios.md)
- [ ] Download the official prep kit for CSA's own sample questions

## Readiness check

You are ready when you can explain, without notes, the difference between: AI, machine learning and generative AI, evasion and poisoning, prompt injection and jailbreaking, a model owner and a model provider, and governance and compliance.
